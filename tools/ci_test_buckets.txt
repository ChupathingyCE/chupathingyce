# Where each test runs (tools/ci_select_tests.py; docs/ci.md, "Which tests
# run"): one test a line, sorted by file, as "<bucket> <test> [paths...]".
#   core      every pull request push
#   area      a pull request that changes the test's paths: what the test
#             names, builds or imports (found by ci_select_tests.py), and
#             any paths given after it here
#   security  as area on a pull request; the merge queue, main and the
#             nightly run every test anyway
#   maps      needs maps or a built game with a data root: the maps
#             runner's nightly only (.github/workflows/maps-tests.yml)
#   local     never in CI
# A test with no line runs on every pull request, and
# tools/test_ci_select.py fails until it has one. A new test goes in area
# unless it guards something every change can break (core), or it is a
# security regression (security).
