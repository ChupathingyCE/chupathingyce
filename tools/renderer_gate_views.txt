# Views for tools/renderer_gate.py (docs/renderer-gate.md).
#
#   <map> <name> player                     the player's own view: HUD, weapon
#   <map> <name> spawn <turn> [pitch]       the debug camera at the player's
#                                           eyes, turned (degrees), no HUD
#   <map> <name> camera x y z yaw pitch     the debug camera at a spot, no HUD
#   map <map> tick=<n>                      the tick this map stops at
#
# A map is as init.txt's map_name: a Custom Edition map is name@ce (from
# maps_ce, --maps-ce), an MCC Workshop level mcc_maps\<item>\<level>
# (from maps_mcc, --maps-mcc). Every map's game stops at --tick (300, ten
# seconds in) unless its map line says otherwise.
#
# A multiplayer map's solo game puts the player at a random spawn, so
# player and spawn views are for campaign levels, whose start is fixed;
# multiplayer maps use fixed cameras, or action:<map>: the map in the
# recorded game of tools/test_determinism.py (its scripted bot playing,
# recorded once and played back on each renderer), stopped at its tick,
# for the HUD, the weapon, shots and effects.
