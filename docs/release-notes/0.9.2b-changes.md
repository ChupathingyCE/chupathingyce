# Chupathingy 0.9.2b: everything since 0.9.2a

Everything that changed on main between the v0.9.2a tag (2026-11-27) and d7ae9c48cf4e (2026-11-28).

## Fixes

- 0.9.2a's 64-bit Windows and Linux zips had a config.toml in them, and updating put it over the player's own, keeping theirs as config.toml.old. At start, the desktop game now puts the old settings back once, only when config.toml is that blank template and config.toml.old has real settings. The blank one is kept as config.toml.template-0.9.2a. The updater never writes config.toml, config.toml.old or config.toml.new, whatever the zip holds, and the builds are checked for player files before they're packaged (#2032, fixes #2029).
- On macOS, a player on Metal is asked once at start: "Metal is still in testing. Switch back to OpenGL?" Yes switches to OpenGL, No keeps Metal. Metal has a bug where some models, the HUD and overlays go missing (#2033, part of #2028).

## New settings

| Key | Default | What it does | Platforms |
|---|---|---|---|
| `display.metal_asked` | `false` | Set once the Metal question is answered, so it's never asked again. | Desktop (only macOS asks) |
