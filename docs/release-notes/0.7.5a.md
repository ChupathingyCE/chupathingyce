## What's new in 0.7.5a

**Custom Edition maps download themselves.** Join a game on a Custom Edition map you don't have and the game offers to download it from the community's public map repositories (HaloNet, the same ones Chimera uses), then joins. `network.map_downloads` in config.toml picks `ask` (the default), `always` or `never`. Each download is checked against the host's version of the map before it's played. If a server moves on to a map you're missing, the game steps out, downloads it and brings you back. Halo PC's own maps are never downloaded: install those yourself.

**Fewer lockouts.** Two Chupathingy games now join each other whatever OpenCE version number either side shows, as long as they speak the same Delta network code. The next OpenCE version is accepted from the day it appears. Games with OpenCE players work as before.

**Cross-play with OpenCE's latest.** Network version 29: a Custom Edition map keeps its own name, and the game says which version of it is being played. Maps saved with the old `name_1a2b3c4d` names still work.

**64-bit Android (testing).** A native 64-bit Android build is on this release as its own download. It installs over the regular app and keeps your maps and saves, so you can switch back and forth. If the regular app doesn't start on your phone, try this one and tell us how it goes. The regular app stays the default for now.

**Fixes**
- Online Games: a held D-pad or stick moves through the list at the menus' pace.
- Linux: no more rare crash when the updater and the game list used a secure connection at the same moment.

**Dedicated server.** A warning reads "Server warning: <reason>" instead of saying "Warning" twice, and `sv_warn`, `sv_kick` and `sv_ban` take a whole sentence as the reason, quoted or not.

Thanks to everyone who reported map and Android problems in the Discord.
