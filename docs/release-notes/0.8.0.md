## What's new in 0.8.0

**Highlights**
- **Text chat.** Talk in games with T (everyone) and Y (team), or quick lines on a controller. Pick how filtered words show (masked, hidden or shown), and turn on streamer mode. Servers can post messages to everyone.
- **Chupathingy menus are the default.** The Xbox's look with Halo PC's extra screens. Xbox and Gearbox menus are still one setting away.
- **Online Games looks like the Xbox menus,** shows each game's ping before you join, and names co-op games by level and difficulty. Co-op games now stay off the server browsers; the website has a "Show co-op games" switch if you want them.
- **Set up from your own copies.** The first start offers an Xbox disc image, a Halo PC CD image, or the Halo Custom Edition installer, and fills in the maps folders. It also copies the disc's movies. Custom Edition maps still download themselves from the community repositories.
- **Change teams during a team game.**
- **Sharper HUD.** High-res HUD art from halopc-restored, plus HD HUD support on Custom Edition maps.
- **Cross-play with network version 32** (see below).

**Playing**
- Follow camera while a long respawn wait runs, as in Halo 2 and 3. Short waits stay as in retail.
- Join public co-op games, also through cross-play.
- Scoreboard shows a small platform logo before each name (Chupathingy menus by default; `display.scoreboard_platforms` to change it).
- The host's END GAME is back in the Xbox menus' pause menu.
- Opt-in: powerup timers, and the classic loading screen.
- Bumper Jumper button layout, kept on the Xbox-style controls screen.
- Ports using SDL now play the loading screen audio.
- Fixes brought over from OpenCE: co-op crash, first-join hang, hit refusals, light state, map hardening, lobby countdown.

**Cross-play with OpenCE (network version 32)**
- Elevators carry riders smoothly, in step with the elevator.
- You can run a second game on one computer, to test or play against yourself.
- A host can switch off mouse aim assist for everyone with the new `network.block_mouse_aim_assist` (off by default); Chupathingy clients honor it.
- Chupathingy games still join each other whatever OpenCE number they show.

**Settings and menus**
- Audio Setup: choose your output device.
- Video Setup is simpler: one Frame Rate row; Instant Aim and other niche options move to `config.toml`.
- Button prompts show the keyboard's keys when you are not on a controller.
- Your own font for the high-res text (`data/fonts`, `display.high_res_font`). The built-in one is now Cyborg Interface Gothic, by fizzy.
- New: far clip distance setting for big maps (`display.far_clip_distance`).
- New-install defaults: 2x multisampling (64-bit desktop builds), 256 shadows, a bigger Android audio buffer. Existing players are asked once before any of their settings change.
- Server Setup defaults to 16 players.
- A held direction steps at the menus' pace on the moderation screen.
- A privacy screen, and `network.report_hosted_games` so a host can stay listed without sending stats. No hardware IDs are sent, and OpenCE players get minimal lines.
- Ask before joining an invite found on the clipboard.
- Menu names are now Xbox, Gearbox and Chupathingy (`display.menus`; "pc" still works).
- Discord presence uses Chupathingy's own app, with a fuller activity.
- Logs go in a `logs/` folder (debug.txt, halo.log, crash reports) on every platform.
- Windows and Linux keep Chupathingy's own save folder (copied once).
- The game window is always opaque.

**Installing and updating**
- The updater reads one signed list of update files, and debug builds can update again.
- New 64-bit Linux AppImage on test builds.
- Windows executable has the Chupathingy icon and version details; the Android app is named Chupathingy.
- Our own disc image reader replaces extract-xiso.
- Release pages are simpler: four download links first, the rest folded away.

**Dedicated server and moderation**
- Chat controls: `sv_say`, `sv_chat`, `sv_mute`, `sv_unmute`.
- Welcome message, postgame length, skip the lobby, and a chat pause.
- Server panel: phone layout, actions by role, one name form, live linking. One list of who can moderate and where each role comes from.
- Password-protected and private games' invites stay off the game list.

**Fixes**
- Campaign: opening the level list no longer crashes on 64-bit builds.
- Chat typing no longer locks the keyboard.
- A refused Custom Edition map says why on screen, and the tag cache message names the room needed and free.
- Android: Quit closes the game; Link Profile works after the first run; the game starts on phones with older kernels; system bars stay hidden; Adreno textures are handled by the game.
- Linux and Android server builds link again.
- Old default Discord application settings follow the current one.
- Mac: macOS zip no longer includes a stray `brokers.txt`.

**Known issues**
- macOS 15.8.2 shows a black screen (an Apple OpenGL regression). Use macOS 15.8.1 or earlier, or macOS 26.
- Menus may ignore the D-pad after the intro movie. We are looking into it.
- In mixed games with OpenCE players, OpenCE's voice chat and vote kick do not reach Chupathingy players. A text chat bridge to OpenCE is coming next.
