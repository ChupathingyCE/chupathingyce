- **Halo 1: NHE map packs play.** Maps in `maps_nhe` no longer stop on the damaged disc screen, and their scripts run. All 27 NHE multiplayer maps load. A map whose script data can't be used now plays without its scripts instead of stopping. Thanks to OpenRift for the report.
- **Skip the intro with the keyboard, mouse or a tap.** Any key, click or touch skips the opening movie again, as a controller does. Thanks to wriggle_nightbug.
- **Dedicated servers: the control panel is on by default,** for this computer only (`127.0.0.1:8080`). The first start shows a one-time setup link and saves it in `control_setup_code.txt`. On Windows it also opens in your browser. Reaching the panel from other computers is still something you turn on. `HALO_DEDICATED_CONTROL=off` turns it off, and the Docker image keeps it off unless you set it. Thanks to XxQs.
- **Android has one download, the 64-bit one.** It installs over the old app and keeps your saves. Thanks to FASTNOOB and Napsta.
- **Custom Edition players on our servers** stay from one map to the next, can start a game on an empty server, and the server shows up in Custom Edition's own list.
