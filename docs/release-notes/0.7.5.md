## What's new in 0.7.5

**Settings that tell you what's wrong.** Editing config.toml now says what happened, in debug.txt:
- A setting you changed but left commented out (`# volume = 0.5`) is pointed out: remove the `# ` to use it.
- One bad line no longer resets every setting. It's skipped and named, with a hint ("text needs quotes", "true and false are lowercase"), and everything else is used.
- Words work in any case (`mode = "Windowed"`), unknown ones are logged, and `display.mode` overriding `display.fullscreen` is said once.
- A `config.toml.txt` (as Windows' Notepad saves it) is pointed out on every desktop build.
- Updating from an old settings file keeps your `menus = "pc"`.

**Service records.** Busy games' carnage reports were cut off and turned away by the site, so those games never reached anyone's record. They're sent whole now.

**Custom Edition maps.** HUD prompts show the Xbox's controller buttons ("Hold X to swap"), not a weapon picture.

**Fixes**
- Escape or End with the console open closes the console instead of resetting the map.
- The weapon HUD shows each weapon's real ammunition: coldsnap's flamethrower no longer flashes "No Fuel" when full, and the assault rifle's bullet bar turns red with its counter when low.
- European discs with a maps folder per language set up (#145).
- Controls saved in Settings apply to players already using that profile (part of #118).
- No Running Riot after one or two kills on a network client (part of #98).
- The mouse wheel no longer bounces between SELECT and BACK under a list (part of #149).
- A Custom Edition sound that fails to decode is left as it was, not half converted.
- 64-bit builds keep their memory blocks 16-byte aligned.

**Dedicated server.** `sv_name_filter 1` warns and then removes players whose name is on the blocked names list (`server/blocked_names.txt`). Off by default.

**Versions.** Hotfixes of a release now add a letter (0.7.5a, 0.7.5b), and the game updates to them.

Thanks to Shade (xshxdex98), whose DamnationCE found several of these fixes, and to FL1THY and everyone who reported bugs in the Discord.
