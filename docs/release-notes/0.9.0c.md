- **Lens flares and light glows on AMD graphics.** Flares, the flashlight's glow and glowing lights were missing on AMD cards with OpenGL. They show again. Thanks to Fujibayashi Kyou for the report, and to chester (GulchCE), whose work this is based on.
- **Safer player names.** A name or message ending in '|' could make the game read past the end of the text. Fixed. Thanks to BirchWood.
- **Fewer crashes.** Clients no longer halt when the host removes a flag or ball. Skipping a co-op cutscene no longer crashes. A projectile or damage no longer holds on to an object that was already removed. Going back from the post-game map list returns you to the main menu.
- **Rendering fixes.** Impact puffs aren't cut off by the floor. Powerups and the overshield draw right over glass. Units are lit and decals appear even before their textures finish loading. Fewer texture reloads at high frame rates. Big levels draw faster, and dense Custom Edition maps keep their far geometry.
- **Co-op and online.** A host that stalls for a long moment stays in its own game. Pelicans and lifepods move smoothly for co-op clients. Co-op no longer makes extra Monitors. Host cheats no longer spawn a flag or ball that other players can't see.
- **Engine and sound.** A bad frame time no longer freezes the game clock. Faster collision checks. Sounds that were stopped don't start again, and looping sounds end when they should.
- **Windows.** Less stutter the first time something is drawn.
- **Menus.** F11's window mode is kept when you save your settings. A map's titles stay under the menus. On Linux, the setup screen says why when it can't open a file dialog.
