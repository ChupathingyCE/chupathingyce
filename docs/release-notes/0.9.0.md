- **The program is now chupathingy.exe** (chupathingy on Mac, Linux and FreeBSD). Shortcuts to halo.exe keep working for now.
- **Map packs of other builds play online.** A map pack whose maps were built by another build of the Xbox tools, such as Halo 1: NHE in `maps_nhe`, now plays in multiplayer instead of saying the map isn't supported. Every player needs the same map file, and these games are played between Chupathingy players only. Thanks to OpenRift for the report and logs.
- **No host cheats in public games by default.** While others are in a public internet game you host, the console can't spawn objects, turn on cheats or change the game speed. Kick, ban and display commands still work. LAN, private and password games are unchanged. Set `network.host_cheats = true` to allow cheats; Online Games then shows "Host cheats on" for your game.
- **OpenCE players who start a vote are told it isn't supported.** In a game you host, an OpenCE player who starts a vote gets one chat line: "Voting isn't supported on this server; ask a moderator." The vote itself is still ignored, and only the fact that a vote was sent goes in the log.
- **Lobby spam is held back.** A game you host now drops lobby requests (settings, player settings, players added or removed) from a machine that sends them much faster than anyone using the menus can. Normal play never hits the limit, and the host's log notes it once per machine.
- **A limit on console-made objects.** In a network game you host, the console and cheats can make 32 objects a game (`network.host_console_objects`), or 8 while an original Xbox is playing. When an Xbox is in the game, objects past its share of the object slots are never kept, so a pile of spawned vehicles can't break the console's game.
