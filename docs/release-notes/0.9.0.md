- **The program is now chupathingy.exe** (chupathingy on Mac, Linux and FreeBSD). Shortcuts to halo.exe keep working for now.
- **Map packs of other builds play online.** A map pack whose maps were built by another build of the Xbox tools, such as Halo 1: NHE in `maps_nhe`, now plays in multiplayer instead of saying the map isn't supported. Every player needs the same map file, and these games are played between Chupathingy players only. Thanks to OpenRift for the report and logs.
- **No host cheats in public games by default.** While others are in a public internet game you host, the console can't spawn objects, turn on cheats or change the game speed. Kick, ban and display commands still work. LAN, private and password games are unchanged. Set `network.host_cheats = true` to allow cheats; Online Games then shows "Host cheats on" for your game.
