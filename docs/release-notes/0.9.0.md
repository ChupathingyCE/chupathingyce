- **The program is now chupathingy.exe** (chupathingy on Mac, Linux and FreeBSD). Shortcuts and scripts that start halo.exe still work in this release; the halo.exe stub goes away in the next one.
- **A setup screen before the game.** It shows your maps (which are ready, what is missing), opens their folders, imports a disc image or the Halo PC and Custom Edition installers, and sends your logs with a short code to paste on Discord. It opens on first run, when maps are missing, or with Shift or Back held at start. With more than one mode installed, it asks once which one to start in.
- **Hosting from the game.** A game you host starts with only you, so there's no waiting for a second player (thanks Mootjuh). Hosts use a fixed port, UDP 2302, so port forwarding works, and when the router can't be set up automatically the status line says which port to forward. Players who changed either setting are asked once.
- **Online Games lists every game.** Co-op games and games from the brokers were being cut off the end of the list. Games with a password show a lock and ask for the password. The keyboard keys on that screen work: F2 opens My Profile (Escape stays Back) and X changes the sort (thanks OpenRift, ugoboom).
- **Plays with OpenCE's newest version.** Joins hosts on network versions 40 and 41, and hosts announce the newest version our signed compatibility table allows, without a new release each time. OpenCE's dedicated servers show in the game list, marked "OpenCE dedicated".
- **Security fixes.** Downloads and the event log are stricter about where they send things, map names that Windows can't store are refused, and release builds can't skip update signatures. Please update.
- **Sound.** Headphone 3D is on by default (players who had it off are asked once).
- **Graphics.** Models with cutouts no longer turn half see-through with anti-aliasing. No fog "shadow" of the weapon when the two field of view settings differ (thanks neoteaika). Chapter titles keep their place on wide screens, scaled HUD meters and overlays are smoothed while text stays sharp (thanks openrift), and the reticle can follow the field of view ("Reticle Follows FOV", thanks Fujibayashi Kyou). Halo PC maps' HUD meters follow the map's "use Xbox shading" flag, so restored and custom HUDs draw right (thanks Aerocatia, OpenRift).
- **Menus.** Real Start and Back button glyphs. Every row of the Xbox menus' pause menu works again (Controls, Change Teams, Moderation, End Game), keyboard keys save as soon as you set them, and controllers switch bind columns. Halo CE+'s own menus load on PC and consoles (thanks Fujibayashi Kyou, openrift, ugoboom).
- **Map packs of other builds play online.** A pack built by another build of the Xbox tools, such as Halo 1: NHE in `maps_nhe`, plays in multiplayer when every player has the same copy. These games are Chupathingy-only (thanks OpenRift).
- **Platforms.** FreeBSD builds, by Renkoto, ship with the release and update themselves (FreeBSD 15). The Linux AppImage ships with every release and updates itself (thanks glitchy8015, ugoboom, _guven). Each platform has its own badge on scoreboards and on the site.
- **Settings file.** config.toml reads like a guide: everyday settings first, plain help for every setting, debug settings at the end.
- **Consoles.** The original Xbox, Xbox 360 and Wii U fetch the game list over HTTPS and can link a Delta profile, and the original Xbox sends its online games to your service record. Console builds follow separately.
- **Stubbs the Zombie, a first look,** in development builds only: bring your own Stubbs Xbox maps, and its menus and first level load. Unit definitions from Sigmmma's reclaimer.
