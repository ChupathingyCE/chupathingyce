- **The program is now chupathingy.exe** (chupathingy on Mac, Linux and FreeBSD). Shortcuts and scripts that start halo.exe still work in this release; the halo.exe stub goes away in the next one.
- **A setup screen before the game.** It shows your maps (which are ready, what is missing), opens their folders, imports a disc image or the Halo PC and Custom Edition installers, and sends your logs with a short code to paste on Discord. It opens on first run, when maps are missing, or with Shift or Back held at start. With more than one mode installed, it asks once which one to start in. Installs without the disc's loading picture now show Chupathingy's own instead of a blank screen.
- **Hosting from the game.** A game you host starts with only you, so there's no waiting for a second player (thanks Mootjuh). Hosts use a fixed port, UDP 2302, so port forwarding works, and when the router can't be set up automatically the status line says which port to forward. Players who changed either setting are asked once.
- **Multiplayer plays as on the Xbox again.** You pick up a second weapon with the action button instead of walking over it, infinite grenades turn off in games of five or more players, a player with no weapon can't throw a grenade, and a weapon swap in the middle of a switch drops the weapon in your hand (thanks OpenRift, Gillian, Fujibayashi Kyou). In team games the betrayer takes the respawn penalty, not the player they killed.
- **Host rules.** Names above heads, the follow camera while you wait to respawn, and changing teams during a game are now off by default, as on the Xbox. The host decides whether its players may use them (Host Setup > HOST RULES). Players who had them on are asked once.
- **Online Games lists every game.** Co-op games and games from the brokers were being cut off the end of the list. Games with a password show a lock and ask for the password. The keyboard keys on that screen work: F2 opens My Profile (Escape stays Back) and X changes the sort (thanks OpenRift, ugoboom).
- **Plays with OpenCE's newest version.** Joins hosts on network versions 40 and 41, and hosts announce the newest version our signed compatibility table allows, without a new release each time. A host announces a newer version only when it has the protections that version needs. OpenCE's dedicated servers show in the game list, marked "OpenCE dedicated". An OpenCE player who starts a vote in your game is told in chat that this host has no votes.
- **Games you host are harder to spoil.** While others are in a public internet game, the console and cheats can't change the game unless you set `network.host_cheats = true` (Online Games then shows "Host cheats on"). Objects made from the console have a limit each game. Lobby spam from one machine is held back, and hits reported through walls are refused. Hosts can also limit how many machines join from one internet address (`network.max_machines_per_address`, off by default).
- **Dedicated servers.** There is now a server for 64-bit Windows, beside the Linux ones. A new server can be set up from its control panel in the browser, with no console needed, and the Status tab answers "Can people join?" with what to fix if not. A new config.toml holds only the settings a server uses. Moderators can see how often the server refused each player's input (`sv_evidence`), and servers can turn on betrayal and AFK limits (off by default) and limit machines per address (8 by default). A typed command stays on its own line while the log scrolls. The new [Host a server](https://github.com/ChupathingyCE/chupathingyce/blob/main/server/docs/hosting.md) guide covers it all.
- **Security fixes.** Downloads and the event log are stricter about where they send things, map names that Windows can't store are refused, and release builds can't skip update signatures. Hosts and servers are also stricter about what other machines send them. Please update.
- **Sound.** Headphone 3D is on by default (players who had it off are asked once). Custom Edition sounds with more than 32 variations play instead of being refused.
- **Graphics.** Models with cutouts no longer turn half see-through with anti-aliasing. No fog "shadow" of the weapon when the two field of view settings differ (thanks neoteaika). Chapter titles keep their place on wide screens, scaled HUD meters and overlays are smoothed while text stays sharp (thanks openrift), and the reticle can follow the field of view ("Reticle Follows FOV", thanks Fujibayashi Kyou). Halo PC maps' HUD meters follow the map's "use Xbox shading" flag, so restored and custom HUDs draw right (thanks Aerocatia, OpenRift). Contrails have their 30 Hz look back, fast first-person moves like a melee swing are smoothed when interpolation is on, and a few rare engine errors are fixed (found in chestahh's GulchCE).
- **A new renderer to try.** The 64-bit Windows, Mac and Linux builds can draw with bgfx: Vulkan on Windows and Linux, Metal on Mac. OpenGL stays the default. Set `display.renderer = "bgfx"` in config.toml to try it, and tell us how it runs ([how to turn it on and report](https://github.com/ChupathingyCE/chupathingyce/blob/main/docs/settings.md#a-new-renderer-to-test)).
- **Menus.** Real Start and Back button glyphs. Every row of the Xbox menus' pause menu works again (Controls, Change Teams, Moderation, End Game), keyboard keys save as soon as you set them, and controllers switch bind columns. Halo CE+'s own menus load on PC and consoles (thanks Fujibayashi Kyou, openrift, ugoboom). The weapon field of view's help text fits its box (thanks snapchipper). On Android, Hide now hides the Options button with the touch controls.
- **Map packs of other builds play online.** A pack built by another build of the Xbox tools, such as Halo 1: NHE in `maps_nhe`, plays in multiplayer when every player has the same copy. These games are Chupathingy-only (thanks OpenRift).
- **Platforms.** FreeBSD builds, by Renkoto, ship with the release and update themselves (FreeBSD 15). Each platform has its own badge on scoreboards and on the site. Jizzy's Steam Link port now builds from Chupathingy's own code, and his iPhone, iPad and Apple TV port is part of the main tree (thanks Jizzy). Their builds aren't part of this release.
- **Settings file.** config.toml reads like a guide: everyday settings first, plain help for every setting, debug settings at the end.
- **Consoles.** The original Xbox, Xbox 360 and Wii U fetch the game list over HTTPS and can link a Delta profile. The original Xbox joins OpenCE's network 41 games, sends the online games you join to your service record, and plays Custom Edition maps on a 128 MB console (experimental on a stock 64 MB one), with a Map Browser for the xboxhomebrew.store archive and missing maps offered when you join (thanks Jizzy). thelinkin3000's Switch port joins network 41 games too, and Mayo's PlayStation 3 port now has its own repository. Console builds follow separately.
- **Stubbs the Zombie, a first look.** Bring your own Stubbs Xbox maps in a `maps_stubbs` folder and pick it on the setup screen: its menus load, and the levels are still in progress. Unit definitions from Sigmmma's reclaimer.
