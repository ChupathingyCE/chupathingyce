- **Security.** The dedicated server's control panel and API are tighter: commands not in the permission table are refused, wrong logins lock out only the source they came from, connections get shorter time limits, and the site link code stays out of the log. Thanks to nickarcade for the report. Games with a password now ask for it on every way in, invite links included: an invite to a game with a password is locked to it, and changing the password makes a new invite. Please update, especially if you host.
- **Fewer crashes.** Busy scenes with many lights no longer corrupt memory on desktop builds (a crash on big maps like Hugeass and Dustbeta). No crash when the player under your crosshair leaves, in long chains of explosions, when leaving a network game from the pause menu, or on a map that names a device group it doesn't have. Graphics without OpenGL 4.5 (4.1 on macOS) get a plain message instead of a crash.
- **Co-op games are back in Online Games,** marked CO-OP, with an All / Multiplayer / Co-op filter.
- **Split screen** works again: each controller drives its own player.
- **Clear reasons when you can't join a game,** the same in both game lists, a failed join and on the site: "Needs a newer Chupathingy", "Game is full", "Map not installed" and the rest.
- **The game list stays up.** Chupathingy's own list comes first, OpenCE's games are added and marked as legacy, and if the list is offline you still see the games found directly.
- **Hosting from the game.** Hosts see whether players can reach them (router port forwarding, network type and port), a join that can't get through says so, and the pause menu has a Moderation screen to kick or ban, with a reason, saved to bans.txt.
- **Sound.** Doppler no longer warbles at high frame rates, and sounds keep their high end (they were cut above about 9.7 kHz).
- **Custom Edition maps.** Maps compressed with Chimera load. Map names with commas, brackets and spaces work (bigassv2,104, skedar v2). HUD icons and zoom masks on maps with high-resolution HUDs draw at the right size. Coldsnap's game type setup runs on dedicated servers. More maps load (cmt_snow_grove_v2, tactics), Ogg sounds at other rates play, and dedicated servers skip a playlist entry they can't play instead of stopping. A Master Chief Collection map says it isn't supported yet instead of failing to load.
- **Android.** A Resolution row in Video Setup, and the buttons after a game you hosted respond to taps again.
- **Performance** (thelinkin3000): the sound mixer and the game no longer wait on each other, a particle limit, the brightest dynamic lights first, cheaper blurs and faster network reads. The particle and light limit settings work on every desktop build again.
- **For packagers.** A `packaged` file next to the program (or `HALO_PACKAGED=1`) leaves updates to the package manager and keeps Linux data in `~/.local/share/chupathingyce`.
- Plays with OpenCE players as before; our dedicated servers keep announcing network version 32 for now.
