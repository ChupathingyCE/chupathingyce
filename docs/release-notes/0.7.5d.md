## What's new in 0.7.5d

**Security**
- Someone who saw a game on the game list could join a password-protected or private game without the password. Games with a password, and private games, are no longer listed by their invite, and an invite that was already listed stops working when you set a password or make the game private.
- Please update. Until you do, if you host a game with a password or a private game, set `network.list_hosted_games = false` in `config.toml`.

Thanks to everyone who reported this.
