# Chupathingy 0.9.2: everything since 0.9.1

Everything that changed on main between the v0.9.1 tag (2026-11-13) and 287780648d6c (2026-11-25). The few pull requests merged after it, up to the release, are at the end. That's 347 merged pull requests (three of them are batch merges of others), about 1,280 commits, and 96 new config.toml settings.

Opt-in means off by default. Experimental means early work that may change.

## 0.9.1a (security release, 2026-11-13)

0.9.1a was 0.9.1 plus one fix. The same fix is on main.

- Workshop items are checked more strictly, so a broken or hostile item can't reach files outside the Workshop folder (#1278).

Several pull requests were tagged "0.9.1a" while that release was planned. They didn't ship in 0.9.1a. They're in 0.9.2 and listed below.

## New settings

All are in config.toml. Unless it says otherwise, a new setting is off or set to retail behavior by default. "Desktop" means Windows, Mac and Linux. "Xbox" means the original Xbox build.

| Key | Default | What it does | Platforms |
|---|---|---|---|
| `display.vrr` | `"off"` | Variable refresh for G-SYNC and FreeSync displays: "on", "off" or "auto". | Desktop |
| `display.hdr` | `false` | Draws the 3D view in HDR and tone maps it before the HUD. | Desktop |
| `display.hdr_output` | `false` | Sends HDR to an HDR display. Needs `display.hdr`. | Desktop |
| `display.hdr_tone_mapping` | `"neutral"` | The tone mapping curve: "neutral", "aces" or "reinhard". | Desktop |
| `display.hdr_exposure` | `1.0` | The 3D view's brightness before tone mapping, 0.25 to 4.0. | Desktop |
| `display.hdr_paper_white` | `0` | The game's white in nits with HDR output. 0 uses the display's. | Desktop |
| `display.hdr_peak` | `0` | The brightest highlight in nits with HDR output. 0 asks the display. | Desktop |
| `display.hdr_ui_nits` | `0` | The HUD's and menus' white in nits with HDR output. | Desktop |
| `display.shadow_filtering` | `true` | Soft object shadow edges, as the Xbox. false draws them sharp. | Desktop, Android |

## Changed defaults

On desktop and Android, a config.toml from an earlier version is asked once before a changed default applies. Values set by hand stay.

- `audio.resampling` is now `"xbox"`, the Xbox's own resampler. It was `"sinc"`. "sinc" and "linear" are still there (#1273).
- `audio.loudness` is new and defaults to `"xbox"`, which is 6 dB quieter than 0.9.1. "louder" keeps the old level (#1658).
- `display.widescreen` on the original Xbox is now `"off"` (4:3). It followed the dashboard before. A file that names "dashboard" keeps it (#1477).
- `debug.structure_culling` is off on consoles where the processor is the limit. Desktop stays on (#1572).
- The dedicated server takes 16 players by default instead of 12 (#1552).
- The drop-down console, the game lobby, the join screen and distance-field text are on by default. Each one has a setting to go back (#1256, #1322, #1267, #1314).
- Two new settings are on by default: OpenSauce post-processing (#1780) and developer flames (#1816).

## Removed

- No settings were removed or renamed.
- The halo and halo.exe stub that started chupathingy under its old name is gone, as the 0.9.0 notes said. Update shortcuts, scripts and Steam entries that start halo or halo.exe. An updater from 0.7.5d or older can't restart the game: start chupathingy once yourself (#1855).
- The JOIN GAME panel in the game list is gone. A, Enter or a click joins straight away (#1267).
- OpenCE's name is out of player-facing text. Online Games and the lobby say "Legacy" (#1333, #1334).
- The campaign pause menu on one machine has no Delta row (#1443).
