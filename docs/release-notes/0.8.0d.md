- **Halo CE+ maps.** Put the maps of Halo CE+ X (by VKMT) in a `maps_cex` folder beside `maps`. They show in the map list marked [CE+] under their CE+ names (Gothra, Magnitude and the rest), and you can host and join them online, on PC and Xbox alike. A player without the same maps is told which one to install instead of loading the retail map. Dedicated servers can run them too (`wizard@cex` in a playlist); [C] CE+ Test runs them now.
- **Clans and Delta Profile in the game.** Your Delta Profile and clan show in the game, and clan tags show in games with other Chupathingy players.
- **Text chat with OpenCE players.** Chupathingy's chat and OpenCE's in-game text chat now reach each other.
- **Game Setup.** Hosts get a Game Setup screen and a game type editor for their games.
- **Controls.** Rebind the controller and the keyboard from every menu style, all on one Controls screen.
- **Settings regrouped** into nested lists, with prompts that follow the device you're using, a setting to start with one player, and small opt-in extras.
- **Smoother at high frame rates:** light fades, HUD flashes, the motion tracker and other effects move smoothly between game ticks, and quick taps stay taps.
- **Big maps** that are larger than the retail cache files load.
- Halo PC maps: stock maps on the game list get the right label, folder and edition, and Custom Edition maps play sounds stored in sounds.map.
- Fixes: dead or misdirected clicks in all three menu sets, a field of view of 70 degrees when the setting is missing, an old invite no longer joining after you join a game another way, and fixes to prompts, weapons, default game types, the sound cache, file copies and text.
