- **Getting back from the Halo CE+ menus.** If you start in Halo CE+, hold Shift or a controller's Back as Chupathingy starts to open the setup screen again. The setup screen now tells you this when you pick a mode to start in. Thanks to ugoboom and OpenRift.
- **Player-hosted online games send a little sooner.** Over the online tunnel to a player's game, messages that must arrive now go out as soon as they are written instead of waiting up to 10 ms or more. Nothing changes in what is sent, so everyone can still play together. The idea comes from goatbutt and the OpenH1 team.
- **Consoles stay in Red vs Blue games.** Xbox players no longer leave a dedicated server with bots as if it were full. Thanks to KenaiPhoenix for the crash log.
