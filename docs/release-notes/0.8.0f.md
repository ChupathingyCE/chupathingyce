- **Play with OpenCE again.** Chupathingy joins OpenCE games on their newest network versions (33 to 36), alongside every older version it already joined. If a game already in progress doesn't add you, join one from its lobby, and tell us in #bug-reports.
- **OpenCE's own game types** (Infection, Gun Game, SWAT and Hardcore) aren't supported yet: in a game running one, Chupathingy leaves with a message saying so instead of falling out of sync.
- **Hosts and servers** can speak OpenCE's newest version to OpenCE players while Chupathingy players, consoles included, play in the same game. They keep announcing the version every build already joins until a server's admin chooses otherwise.
- **Online Games** lists OpenCE lobbies of every version, marked when this build can't join them, instead of hiding them.
- **Credits** name contributors by their GitHub handles.
