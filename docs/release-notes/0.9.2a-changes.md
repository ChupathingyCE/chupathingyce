# Chupathingy 0.9.2a: everything since 0.9.2

Everything that changed on main between the v0.9.2 tag (2026-11-25) and a6bfe4e3c502 (2026-11-27). That's 85 merged pull requests and about 300 commits. There are no new config.toml settings.

Early means work that may change. SPV3 and OpenSauce are early, on the 64-bit desktop builds only.

## Highlights

- SPV3 installs from the setup screen. Maps has an ADD SPV3 row: pick SPV3 3.3.0's release zip or the folder it unpacked to. Bring your own copy (#2001).
- SPV3 starts its levels from its own menus (#1969), and its main menu and loadout screen draw as on Halo PC (#2008, #2009).
- SPV3's post-processing on bgfx too (#1965), its skies and lightmap sets (#2005), its movies (#2007), its four grenade types (#1978) and its actor transforms (#1971).
- SPV3's own scripts run without turning on `lua.scripts`, and a new profile's first campaign starts (#2020).
- OpenSauce maps outside SPV3: a `maps_os` folder, and OpenSauce mods with their own menus as modes in Play. Maps that need OpenSauce's extras play offline and on System Link for now (#1998, #1999, #2000).
- Workshop pages show an item's whole description (#1996).
- DIRECT IP is a row in System Link's list (#1883).

## SPV3 and OpenSauce

### Installing

- The setup screen's Maps has an ADD SPV3 row. It takes SPV3 3.3.0's release zip, or `manifest.bin` in the folder it unpacked to, and checks it's 3.3.0. It writes only the files the game uses into `maps_spv3` and `lua/spv3`: the maps, the resource maps, the three movies and the Lua scripts. No `.exe` or `.dll` is written or run. Each file is checked as it's written, so a second run resumes or repairs. 64-bit desktop only (#2001).
- Make the folders also makes `maps_spv3` (#1884).
- docs/spv3.md covers the installer and what works now (#2015).

### SPV3

- Choosing a level and difficulty in SPV3's menus starts the level. It used to sit on the loading screen (#1969).
- The main menu has no stray CAMPAIGN label, opens on CONTINUE, and shows its highlight band (#2008).
- The loadout screen draws its LOADOUTS heading, its text and ACCEPT. Other menus' title overlays that used the same layout draw too (#2009).
- Post-processing draws on bgfx as it does on OpenGL: tone mapping, visor and HUD overlays, lens dirt, film grain, AO, depth of field, reflections, motion blur, light shafts and bloom (#1965).
- Skies and lightmaps switch when SPV3's scripts ask, on a30, b30, d20, d30, d40 and a50. A checkpoint keeps them (#2005).
- Cluster and anti-matter grenades are kept, thrown, picked up and counted on the HUD, and a checkpoint keeps the counts (#1978).
- Enemies can transform as SPV3's tags say, such as Elites going berserk and the Flood taking over Marines. The host decides and clients follow (#1971).
- Its movies play: `attract.bik` at start and the credits at the end. `display.skip_intro` skips the start movie. A map pack's own movies come before the game's (#2007).
- Its scripts can turn the music and effects down. That's on top of your own volume, and it resets at every map (#2006).
- The DMR's reticle no longer shows a flat blue square, and its compass arcs show only when zoomed. Three-map HUD overlays on OpenSauce maps draw as Halo PC draws them (#1946).
- SPV3's own Lua scripts in `lua/spv3` run in SPV3 mode without `lua.scripts`. Only the files the installer writes are read; an extra or edited file is refused and logged. Your own scripts still need `lua.scripts` (#2020).
- A new profile's first campaign starts instead of sitting on LOADING (#2020).
- `cheat_all_weapons` no longer halts SPV3 levels. SPV3's trap for it still fires, and the level reverts to its checkpoint (#1933).

### OpenSauce maps outside SPV3

- OpenSauce maps go in `maps_os`, beside `maps_ce`, and play with `maps_ce`'s resource maps. Their campaigns show in Load Level (#2000).
- A folder `maps_<name>` with a `ui.yelo` is an OpenSauce mod. It shows as a mode in Play with its own menus, like a map pack. Its scripts can do no more than any map's (#2000).
- Maps that need OpenSauce's extras play offline and on System Link for now. Online games refuse them with "OpenSauce maps play offline for now." A map that asks for memory upgrades stays out of the multiplayer lists (#2000).
- Any OpenSauce map gets the map log and its memory upgrades, not only SPV3 (#1998, #1999).
- Make the folders makes `maps_os` with a README.txt, and docs/maps.md has an OpenSauce maps section (#2000).

## Fixes

### Menus and UI

- Workshop descriptions are no longer cut at 400 bytes. The page keeps paragraphs and scrolls through the whole text (#1996).
- DIRECT IP is the last row of System Link's list in the Chupathingy menus. A, Enter or a click opens it. X still works. The Xbox menus are unchanged (#1883).
- Make the folders also makes `maps_cex`, `maps_spv3` and `maps_mcc`, each with a short README.txt (#1884).
- Video Setup's Interface labels and help text are back on their own rows, and HDR SETUP has no stray FOLLOW CAMERA row (#1932, fixes #1682 and #1986).
- Nightlies stop asking to update to the release they already have. Release builds are unchanged (#2023).
- Select Map draws Custom Edition map pictures when `maps_ce` has MCC's or Halo PC's bitmaps.map, not black boxes. By BirchWood (#1876).

### Crashes

- An unknown command in init.txt no longer crashes the game at start (#1973).
- A script that uses an object after it's deleted no longer crashes. 76 script commands now treat it as none. By BirchWood (#1877).
- CE+ Xbox's Museum no longer halts debug builds or draws its frame twice (#1931).
- Workshop answers read on several threads at once no longer overwrite each other (#2016).

### Graphics and HUD

- The first-person vehicle seat view no longer judders at 144 Hz, 165 Hz or uncapped. The third-person camera's pop is fixed too (#1974).
- Custom HUDs on Custom Edition maps, like Shipment's, no longer draw black on OpenGL or bgfx (#1967).
- bgfx draws Halo PC HUD meters and alpha-tested leaves as OpenGL does (#1652). Its first-person weapon matches OpenGL (#1997).
- bgfx draws per-pixel lighting and the Light effects' model lighting (#1963).
- Closing the game during a hung load no longer sends the next start back to OpenGL from Vulkan (#2017).
- Lens flares clear on a BSP switch, and muzzle flash, emitter, Covenant and rocket lights reach what they light. From chestahh's GulchCE lighting work (#1954).
- Sight and sound tests that skip bipeds walk a shorter list in crowds. What they hit doesn't change. From chestahh's GulchCE work (#1957).
- On halopc-restored's maps, the sniper scope's ticks sit where the Xbox draws them. By BirchWood (#1889).
- The HD HUD's ammo and grenade counters on Xbox maps sit as on Custom Edition maps. By BirchWood (#1890).

### Sound

- Big Custom Edition and OpenSauce mods no longer lose sounds when the 512 MB decoded sound file fills. Sounds that don't fit are decoded when they play (#2019).

### MCC maps

- Change Name and Change Color in the pause menu's settings show ui.map's pictures, on Custom Edition maps too. By BirchWood (#1891).
- The vehicle health panel no longer mixes two sets of icons. By BirchWood (#1892).
- A long objective wraps in the pause screen. By BirchWood (#1893).
- The ammo and grenade counter outlines stay MCC's own, so the panel color no longer shows past them (#2014).

### Stubbs (early, opt-in)

- Armed humans carry their weapons again (#1949).
- Animations' effects play: finishing moves, stealth kills and idles (#1950).
- Hit reactions and short weapon class lists are kept (#1951).
- His two extra surface types keep their footsteps and impacts, on the desktop (#1960).
- Broken maps can no longer crash Stubbs mode's tag conversion (#1994).

### Platforms

- On a 32-bit Windows PC, the Windows 32-bit build says where to get Chupathingy32, with an Open page button (#1945).
- Chupathingy32's Windows build finds room for its memory window on 32-bit Windows. Other builds are unchanged (#1952).

## Removed

- `console.simulate_64mb` and `console.large_caches`, which the original Xbox no longer used. An older config.toml with them still loads (#1943).

## Known issues

- SPV3 and OpenSauce are early.
- SPV3's third and fourth grenade counts, its sky and lightmap sets and its music gains don't reach online co-op clients yet (#1978, #2005, #2006).
- On bgfx with Vulkan or Direct3D 11 and anti-aliasing on, SPV3's depth effects don't draw. OpenGL and Metal draw them (#1965).
- The rest of SPV3's list is in [#1808](https://github.com/ChupathingyCE/chupathingyce/issues/1808).
- Still open from 0.9.2: blank pause menus on a few Custom Edition maps (#1866), the co-op map list and elevators, joins timing out at game start, a crash after a split screen player leaves (#1325), Android heat, the Frame Rate row with V-Sync, clips without video in browsers, and Workshop downloads at a map change.

## Under the hood

- CI runs in tiers with a merge queue, each pull request runs the tests its files need, map tests run nightly, and fuzzing replays saved inputs (#1962, #1981, #1983, #1990, #1993). Old tests fixed and more in CI (#1937, #1976, #1977, #1979, #1980, #1982, #1964).
- Code cleanup: one SHA-256, one Vorbis decoder, one ADPCM table, shared byte and map readers, and unused code removed (#1885 to #1888, #1908 to #1914, #1938 to #1942, #1944).
- Tools to check bgfx against OpenGL, and bgfx shaders compiled in CI (#1627, #1953, #1956).
- A fuzz target for texture decoding, with one bounds fix. By BirchWood (#1878).
- A wider split screen leave test (#1936).
- FFmpeg's LGPL-2.1 license is in THIRD-PARTY-NOTICES.txt for every build that links it (#2007).
