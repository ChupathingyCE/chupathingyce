# Blocked names: names nobody may play or be shown under.
# Shared by the ChupathingyCE site and the dedicated server (sv_name_filter);
# keep both copies the same.
#
# One entry per line: <kind> <word>. Words are written in ROT13 so the list
# doesn't print slurs when it's read or searched.
#   anywhere  blocked when the word appears anywhere in a name
#   whole     blocked when it is the whole name
#   allow     a harmless word containing a blocked one; it is taken out of
#             the name before the "anywhere" words are looked for
#
# A name is compared as its key: lower case, accents dropped, spaces . _ -
# dropped, digits at its end dropped, digits and signs that stand for
# letters read as those letters (0 o, 1 i, 3 e, 4 a, 5 s, 7 t, 8 b, @ a,
# $ s, ! i, | i) and Cyrillic/Greek look-alikes as Latin letters, then
# anything that isn't a-z dropped. Each word is looked for in the key and in
# the key with repeated letters squeezed to one ("aaa" -> "a").
